# 思考 or 不思考（astrbot_plugin_think_gate）

让机器人**更智能地选择本轮要不要深度思考**：每次主模型真正回复前，先用判断模型看一看对话需求，再决定是否临时打开**同一主模型**的深度思考。

- 不另开「思考专用」聊天提供商，只改当前主模型的 `custom_extra_body`
- 默认 **关闭**；关掉时不做判断、不改 thinking
- 默认 JSON 适配 DeepSeek 的 `thinking.enabled / disabled`（可改成你主模型需要的格式）

仓库：https://github.com/Yucheng-Z/astrbot_plugin_think_gate

## 它做什么

深度思考并非每句话都合适。有的回合需要推敲、组织、多步推理；有的只是打招呼、接梗、短确认。本插件在中间加一层路由，让选择更贴近当前对话：

1. 判断模型根据用户最新消息输出 **0–100** 分（需要深度思考的程度）
2. 与「思考浓度」比较：`分数 ≥ (100 − 浓度)` → 本轮开思考，否则保持/使用非深度模式
3. Agent 整轮结束时恢复基线，避免思考开关一直留在上一轮的状态

你可以用浓度把整体风格调得更爱想、或更克制，但核心是**按内容决策**，而不是固定全开或全关。

## 安装

- **插件市场**：搜索「思考 or 不思考」或 `astrbot_plugin_think_gate`
- **手动**：克隆/下载本仓库到 AstrBot 的 `data/plugins/astrbot_plugin_think_gate/`，面板里重载插件

## 快速开始

1. 插件配置里打开 **`enable`**
2. **`judge_provider_id`**：选择用于打分的模型；留空则用当前会话聊天模型
3. **`think_density`** 先用默认 `50`，再按你希望的「爱想程度」微调
4. 主模型若不是 DeepSeek 风格 thinking，改 `thinking_enabled_body` / `thinking_disabled_body` 以匹配 API

## 配置说明

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `enable` | `false` | 总开关。关 = 不判断、不改 thinking |
| `think_density` | `50` | 思考浓度 0–100，**越高越容易进入深度思考**。开启阈值 = `100 − 浓度` |
| `judge_provider_id` | （面板可选） | 判断用提供商；找不到或留空 → 回退当前聊天模型 |
| `judge_timeout` | `5` | 判断超时秒数；超时 / 失败 → 本轮不开启深度思考 |
| `judge_prompt` | 见面板 | 系统提示，应要求模型**只输出一行 0–100 整数** |
| `thinking_enabled_body` | `{"thinking":{"type":"enabled"}}` | 判定「要思考」时写入主模型 `custom_extra_body` |
| `thinking_disabled_body` | `{"thinking":{"type":"disabled"}}` | 恢复/关闭时使用的 JSON（并作基线参考） |

### 浓度怎么理解（举例）

| 浓度 | 阈值（分数 ≥ 才开） | 大致体感 |
|------|---------------------|----------|
| `30` | `70` | 更克制，只有评分较高时才进入深度思考 |
| `50` | `50` | 中性（默认） |
| `70` | `30` | 更积极，评分稍高就会开思考 |

## 行为细节

- **同一 Agent 轮只判断一次**；工具调用触发的后续 LLM 请求会复用第一次结论
- **去标点后有效字符不足 8 个**的短句直接跳过判断 → 本轮不开启深度思考
- 判断结果解析：优先抓整数分；若模型只回 `yes`/`no`（或「是」「否」等）会兜底映射为 100 / 0
- 多会话并发时用引用计数，避免互相踩踏 thinking 开关
- 仅在 `on_agent_done` 恢复；不会在半截回复后提前关掉本轮思考

## 注意

- 依赖主模型提供商配置里可写的 **`custom_extra_body`**；若提供商忽略该字段，本插件无法生效
- 判断也会引入一次短请求；超时或解析失败时，本轮保守地不开启深度思考
- 本插件是按条消息临时覆盖 thinking；与提供商面板里写死的默认值配合使用
